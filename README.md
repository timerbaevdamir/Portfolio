# Портфолио

Небольшой сайт, который показывает вайб-код-прототипы **живыми** — каждый
развёрнут отдельно и встроен сюда фреймом.

## Как это устроено

Прототипы **не являются частью этого проекта**. У каждого свой репозиторий,
свои зависимости, своя сборка и свой адрес; о существовании портфолио они не
знают. Здесь лежит только список и обвязка вокруг фрейма.

Так сделано намеренно. Прототипы собраны на разных стеках и разных версиях —
собрать их в одну сборку значит однажды получить два мажора Tailwind в одном
дереве зависимостей и общую точку отказа: сломался старый прототип, не
собирается портфолио. Фрейм даёт полную изоляцию за цену одного запроса, и
запрос откладывается до момента, когда читатель до проекта долистал.

Переключатель ширины ничего не перезагружает: фрейм рендерится в реальных
координатах устройства и целиком масштабируется под колонку, поэтому
приложение внутри не знает, что его показывают маленьким, и честно
перестраивается по собственным медиазапросам.

## Добавить проект

Одна запись в `src/data/projects.ts`. Больше ничего.

## Разработка

```
pnpm install
pnpm dev
```

`pnpm build` — сборка, `pnpm typecheck` и `pnpm lint` — проверки.

Маршруты настоящие (`/p/<slug>`), поэтому хостингу нужен один rewrite на
`index.html` — он описан в `vercel.json`.
